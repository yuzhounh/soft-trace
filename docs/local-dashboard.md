# 本地网页与每日记录

## 使用方式

当前开发源码采用托盘采集进程 + 本地 SQLite + 本机网页。正常启动、托盘左键或“打开 SoftTrace”打开默认浏览器；`--background` 只启动采集和托盘，不弹出网页。关闭网页不会停止记录，托盘“退出”才会退出进程。

日视图显示实际使用、空闲、首次和最后活动；软件用时下方是活动时间轴和逐段明细。时间轴支持拖拽选区、预览、放大筛选、继续拖选、恢复全天及时间定位；明细按与选区重叠筛选并保留原始起止时间，普通点击可双向定位。选区不影响当天概况及软件用时。明细全部加载，在固定高度卡片内滚动；仍可搜索软件/进程/标题、按软件或状态筛选。页面每 15 秒刷新，隐藏时停止刷新，重新显示时更新；拖选期间暂停开始新的自动查询。

## 周、月、季度、年与全部时间（v0.6.0）

首页提供日、昨天、周、月、季度、年、近 7/30 天、近一季度/一年、全部时间和自定义范围。周从星期一开始，月、季度、年使用自然日历边界；近一季度/一年沿用原统计窗口向前回溯 3/12 个日历月的口径，月底日期取有效日期。方向键切换周期，快捷按钮回到当前周期。自定义起止日期包含结束日，结束日不能早于开始日或晚于今天。全部时间从该设备最早记录的本地日期开始。概况、趋势和软件用时共用所选范围和设备，汇总按浏览器时区拆分跨午夜区间，未来日期不计入。

较长周期展示实际使用、日均使用、活跃天数、软件数量和使用趋势。日均按有软件活动记录的日期计算。周、月、季度趋势按天展示，点击日期回到当天时间轴；年及超过 100 天的范围按月展示，点击月份进入月视图。各视图共用软件用时卡片，可切换左侧环形图/右侧列表与上方占比条/下方列表，记住布局偏好；图表显示前 9 项及 Others，列表展示全部软件，默认每页 20 条，可选 50/100/200 条或全部，不设内部纵向滚动条。图表与列表双向悬停联动，环形图在卡片内随页面滚动保持可见。汇总沿用原记录，不增加网站分析或接入 Time Lens。

新增 `/api/overview` 在本地一次读取所选区间，按日拆分并汇总，不逐天发出大量网页请求。日视图与周期实际使用均按活动区间并集计时。账号头像通过受令牌保护的本地 `/api/account/avatar` 读取已有 Google 资料中的头像，不向网页暴露登录凭据；头像不可用时显示通用用户图标。

这两项接口自 v0.6.0 起纳入完整本地包，仅刷新网页不能替代接口更新。网页依据服务能力禁用旧托盘不支持的周期选项，保留原日视图，头像使用用户图标占位。运行版本以实际进程与 `.tools/local-upgrade/receipt.json` 为准。

v0.6.1 纳入托盘退出后的进程结束修复：先关闭网页服务、停止同步任务并保存最后活动段，再结束自身进程，避免残留前台线程继续占用单实例。隔离进程回归覆盖普通退出及残留前台线程两种场景，均以退出码 0 结束、HTTP 监听关闭且无未关闭记录。界面包含完整周期横轴、固定间隔刻度、年份/月度范围括号、完整展开的软件列表、等高软件分布与悬停联动。设置改为随内容调整高度，提供并排浅深色选项、采集设置自动保存、完整设备 ID、紧凑设备编辑、中文文件选择及同行导入导出按钮；头像加载后真正隐藏 SVG 占位图。

## 多日使用规律（v0.8.0）

使用规律放在多日趋势下方，以标签切换分析，沿用当前设备、日期范围和明暗主题。日视图保留时间轴和逐段明细。24 小时分布要求范围至少两天且至少两个有记录日；星期规律要求实际范围至少七天且至少两种星期有记录。学期与寒暑假对比只在年度、近一年视图，以及跨度至少 365 天的全部时间/自定义范围显示，同时至少有两个已核对阶段存在记录。条件不足时隐藏对应标签，不展示空图；本周等未满七天的当前周期只显示符合条件的分析。

实际使用沿用每日时间轴的活动区间并集，跨小时、跨午夜拆分；空闲、锁屏等已记录状态不增加使用时长。24 小时分布按每个小时有记录的日期分别计算日均分钟数，星期与校历阶段按各组有记录日计算日均小时数。无记录不补零；只有空闲等状态的记录日可以为零使用。页面注明有记录日、无记录天数及查看时区，部分日期的记录可能不完整。原概况的活跃天数和日均口径保持不变。

月份采用固定分组：寒假为 2 月，暑假为 7–8 月，春季学期为 3–6 月，秋季学期为 9 月至次年 1 月。按月份估计各阶段，不对应某所学校或个人实际休假；不再使用逐年校历日期和来源链接。

## 数据与口径

- 保留 `%LOCALAPPDATA%\SoftTrace\softtrace.db`、现有设备 ID、登录和同步配置。数据库只增加 `window_title` 与 `kind` 列，历史记录默认为软件使用，标题为空；不清空、重建或补造历史状态。
- 每秒观察前台软件和窗口标题，软件或标题变化时切段。Chrome 在软件排行中是一个软件，标题仅供逐段回溯；不接入 Time Lens，也不采集网站域名、完整 URL、网页正文或键盘内容。应用自己显示在标题中的网址可能随标题保存。
- 连续无键鼠输入达到空闲阈值后，从最后输入边界回溯截断本次连续活动的尾部，避免动态标题更新把空闲计为软件使用。阈值保留已有设置，默认 3 分钟。空闲是无输入状态，不能直接证明人离开。
- 分别保存空闲、锁屏、睡眠、会话断开、主动暂停、无法识别前台窗口；写入失败会暂停采集，成功恢复后保存故障时段。应用未运行、突然断电或无法恢复原因的空档显示“未记录”，不认定为睡眠/离开/关机。
- 首次/最后活动来自软件使用区间，不等于开机/关机时间。时间轴按查看页面的本机时区裁剪到所选自然日，今天只显示到当前时间；跨午夜区间按天截断。每日实际使用按软件活动区间的并集计算，状态不计入软件排行。
- 采集精度约 1 秒，持久化检查点 15 秒，网页刷新 15 秒；刷新不是实时取样。断电后的最后一小段可能未保存。
- 软件和状态区间沿用现有稳定同步 ID。Firestore 新增标题与类型字段，旧文档缺失字段时兼容读取。状态的云端 `startUtc` / `endUtc` 使用零时长兼容表示，真实边界放在 `stateStartUtc` / `stateEndUtc`；新版恢复状态，旧版的软件排行不会增加状态时长。
- JSON 导出格式为 v2，增加标题和状态类型；兼容导入旧版导出。ManicTime 导入继续保留现有软件记录优先规则，历史标题/状态不在本阶段补导。

## 本地接口

从 v0.5.0 起，网页 HTML/CSS/JavaScript 使用独立文件，每次请求读取文件并发送 `Cache-Control: no-store`，无 CDN、外部字体或 Node 服务。在本项目原目录运行时，开发构建和日常完整包均读取 `D:\Archives\20260914 Soft Trace\src\SoftTrace.App\Web\`，修改这里的界面文件后刷新当前网页即可生效，无需重建或重启采集进程。独立解压或安装到其他目录时，读取 EXE 旁的 `Web/`，完整包必须保留这个目录。图标沿用已有 `Assets/SoftTrace.ico`，独立包对应 `Web/brand.ico`。

新增子目录里的 JS、CSS、图片与字体文件也可直接被页面引用。静态服务限制在网页目录内及允许的网页资源类型，不提供目录列表或用户数据库。采集、数据库、登录、同步和接口等 C# 逻辑改动仍需构建并更新托盘程序；进程重启后的端口可能变化，应从托盘重新打开网页。

进程内 Kestrel 只监听 `127.0.0.1` 的动态端口；API 需要进程级随机访问令牌，验证回环来源与 Host，禁止跨源访问。浏览器入口用 URL fragment 交付令牌，读取后清除 fragment，保存在当前标签页会话中。不要分享带令牌的入口链接。

开发机需要 .NET 10 SDK 及相应 Windows Desktop / ASP.NET Core 运行时。自包含发布通过 `build.ps1` 打包所需运行时。2026-10-18 已生成本地 v0.4.0 完整便携包与安装包，未推送远程发布。进程重启会改变端口与令牌，从托盘重新打开页面即可。

v0.4.0 的便携 ZIP 与安装包包含同一发布目录中的自包含 EXE 和 `Assets/` 图标资源；解压便携包时保留目录结构。包和源码输入的校验清单保存在 `dist/SoftTrace-v0.4.0-manifest.json`。
