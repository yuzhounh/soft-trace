# WPF 使用记录表格列宽

本文保留 **v0.4.0 及此前 WPF 原生管理窗口**的 `UsageDataGrid` 列宽设计，作为历史说明。后续开发源码已将账号、数据管理及范围统计迁入网页，并移除了旧窗口及专用布局代码；本文不定义网页时间轴、逐段明细或软件排行布局。网页功能见 [本地网页与每日记录](local-dashboard.md)。

## 默认布局

四列依次为软件、进程、使用时长、占比，默认采用 `32* / 26* / 28* / 14*` 的 WPF Star 权重，即表格可用内容宽度的 32%、26%、28%、14%。各列随视口伸缩；窄窗口中最小列宽可以暂时优先，窗口放大后继续按比例分配。

软件名和进程名使用单行省略，悬停显示完整名称。较长名称不通过无限扩大整列挤占时长与占比空间。

## 手动调整与恢复

- 表头分隔线支持拖动，每次只调整分隔线相邻两列，其他列保持不动；遵守列的最小、最大宽度约束。
- 拖动期间暂时使用像素宽度固定各列，完成后将四列宽度归一化，转回 Star 权重。
- 完成的四列比例以不依赖区域设置的数值格式、分号分隔，保存到本地设置 `usage_column_ratios`；取消拖动则恢复原宽度，不保存。
- 窗口重新打开时恢复有效的四列比例。设置缺失、列数不符、包含非有限数或非正数等无效值时保留默认比例；不恢复旧像素宽度设置。
- 普通窗口缩放不会回写保存比例，避免窄窗口下的临时最小宽度改变用户设置。
