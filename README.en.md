Soft Trace is a lightweight Windows utility that tracks active foreground applications locally on your machine, summarizing usage by app and category without uploading any data.

## Features

- **100% Local & Private**: No analytics tracking or cloud upload; all data stays on your PC.
- **Accurate Foreground Tracking**: Distinguishes active work from background processes.
- **Daily & Weekly Reports**: Clean rankings and timelines of application usage.
- **Low Resource Overhead**: Minimal CPU and memory footprint.

## Build & Run

```powershell
dotnet build -c Release
```
