用简单的方式，了解使用习惯

自动记录

识别前台软件，自动累计使用时间；空闲、锁屏和睡眠时暂停计时。

清晰回顾

按日期查看软件使用排行，了解不同应用的时间分配。

数据由你管理

本地 SQLite 保存记录，支持导入 ManicTime 历史数据及 Google 账户同步。

开始使用

  1. 从 GitHub Releases 下载 Windows x64 安装版或便携版。
  2. 运行程序后保持托盘常驻，正常使用电脑即可开始记录。
  3. 从托盘打开统计界面；需要结束采集时选择“退出”。
